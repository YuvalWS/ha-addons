# YuvalWS Home Assistant add-ons

Add to Home Assistant: **Settings → Add-ons → Add-on store → ⋮ → Repositories**, then
`https://github.com/YuvalWS/ha-addons`.

| Add-on | What it is |
|---|---|
| [`ha_ro_mcp`](ha_ro_mcp/DOCS.md) | [ha-mcp-readonly](https://github.com/paulomac1000/ha-mcp-readonly) as an add-on: a read-only (RO) MCP server (states, templates, logs, registries) for an AI agent |
